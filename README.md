# La mia scheda palestra

App web statica, senza dipendenze. I carichi e le spunte vengono salvati nel browser del dispositivo.

## Pubblicazione con GitHub Pages

1. Crea un nuovo repository GitHub. Se vuoi che il sito sia raggiungibile da chiunque abbia il link, rendi il repository pubblico.
2. Carica **tutti i file contenuti in questa cartella** nella cartella principale del repository.
3. In GitHub apri **Settings → Pages**.
4. In **Build and deployment**, scegli **Deploy from a branch**, seleziona `main` e la cartella `/ (root)`, poi salva.
5. Attendi che GitHub Pages mostri l'indirizzo del sito.
6. Su iPhone apri quell'indirizzo in **Safari**, tocca **Condividi → Aggiungi alla schermata Home**.

Il sito è statico e non contiene credenziali o dati personali. I carichi e i progressi restano sul dispositivo e nel browser in cui li inserisci.
